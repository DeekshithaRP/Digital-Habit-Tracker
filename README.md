# 📌 Digital Habit Tracker

A full-stack web application that helps users build and maintain positive habits by tracking their daily progress. The application allows users to create habits, set goals, receive reminders, and monitor their consistency through an intuitive interface.

---

## 🚀 Features

- 🔐 User Authentication (Login & Registration)
- ✅ Create, Update, and Delete Habits
- 📅 Daily Habit Tracking
- 🎯 Goal Management
- ⏰ Reminder Management
- 📊 Track Daily Progress
- 💾 Secure MySQL Database Integration

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/DeekshithaRP/Digital-Habit-Tracker.git
```

### 2. Navigate to the project

```bash
cd Digital-Habit-Tracker
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

### 5. Configure MySQL

- Create a MySQL database.
- Import the database schema.
- Update your database credentials in `backend/db.js`.

### 6. Start the Backend

```bash
cd backend
npm start
```

### 7. Start the Frontend

```bash
cd frontend
npm start
```
